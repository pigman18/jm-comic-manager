ci: 随仓库提供 Inno Setup 简体中文语言文件

CI 的 Build installer 步骤失败：

  Error on line 26 in packages\desktop\setup.iss:
  Couldn't open include file
  "C:\Program Files (x86)\Inno Setup 6\Languages\ChineseSimplified.isl":
  The system cannot find the file specified.

原因：Inno Setup 官方安装包只带英文等少数语言，简体中文是社区翻译
（https://jrsoftware.org/files/istrans/），不会随 ISCC 一起安装。
本地能构建成功是因为手动往安装目录放过该文件，CI 全新环境没有。

改法：
- 把 ChineseSimplified.isl（20.9KB，UTF-8 无 BOM）纳入
  packages/desktop/build/languages/
- setup.iss 的 MessagesFile 从 compiler:Languages\ChineseSimplified.isl
  改为相对路径 build\languages\ChineseSimplified.isl

验证：临时把系统安装目录下的 ChineseSimplified.isl 改名（模拟 CI 全新环境），
重新执行 npm run build:installer 仍成功产出 20.08MB 安装包，随后恢复原文件。
