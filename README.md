# JM漫画管理器

> 一个面向 JM 漫画的 **本地搜索与下载辅助应用**  
> ⚠️ **第三方个人项目，仅供学习与研究使用，严禁用于任何商业或非法用途**

---

## 🤔 为什么做这个应用

在长期使用网页版的过程中，总会遇到一些琐碎但影响体验的问题：

- 下载任务偶尔失败，便被遗忘在角落，时间一长也就不再想起去下载它；
- 下载到本地的漫画只剩下编号，难以检索以及还原作品名称；
- 想要根据特定 tag 筛选符合口味的漫画时，本地资源又几乎无从下手。

为了缓解这些碎片化痛点，这个应用将**下载、本地搜索与灵活配置**整合进来，让漫画检索与管理更加直观、高效。

---

## ✨ 功能简介

- ⬇️ **便捷下载**：支持章节级批量下载，大幅降低中断风险，并支持断点下载
- 📚 **本地搜索**：一键检索本地漫画资源，快速定位已下载作品
- 🏷️ **标签筛选**：按标签 / 作者 / 作品 / 角色检索本地库
- 🖥️ **桌面应用**：Windows 桌面端为**推荐也是唯一的图形交付形态**（安装版或免安装版）

---

## 📦 下载与安装

| 文件 | 适用场景 |
|---|---|
| `JM-Setup-<版本>.exe` | **推荐**。Windows 安装版，带开始菜单与桌面快捷方式 |
| `JM.zip` | 免安装绿色版，解压即用 |
| `jm.core.all.js` | 命令行 / 服务端。打包好的 core（含依赖），需配合 Node 22 运行 |
| `jm.core.js` | 命令行 / 服务端。轻量版 core，部分依赖需自行 `npm install` |

> 使用前请确保已安装 **WebView2 运行时**（Win10/11 一般已自带）。

> **1.0.3 起不再发布 `jm.core.exe`**：CLI 用上面的 js 版即可（`node jm.core.all.js --help`），
> 桌面端安装包内也已自带一份 core。

**关于关闭行为**：关闭窗口即退出应用（不再最小化到托盘，也不会残留后台进程）。
